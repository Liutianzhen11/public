# 彩色共享箱子 / Color Shared Chests 1.0.5

[English documentation](README.en.md)

这是实验版本。建议先在测试存档验证，安装前备份。尚未全面验证联机并发、Automate 和新版滚动界面，不承诺兼容所有模组。

## 安装

1. 安装 SMAPI，退出游戏并备份存档。
2. 将编译好的发布包解压到 `Stardew Valley/Mods/ColorSharedChests`，确保该目录直接包含 `manifest.json` 和 `ColorSharedChests.dll`。
3. 通过 SMAPI 启动游戏。推荐安装 Generic Mod Config Menu，在其中修改本模组设置；未安装时可退出游戏后编辑 `config.json`。

GitHub 的源码下载包不等于可直接使用的安装包，需要先编译。不要将别人的游戏 DLL 或整个 Mods 文件夹一起打包。

## 配置项

| 配置 | 默认值 | 说明 |
|---|---|---|
| EnableCapacity | false | 是否增加箱子容量 |
| ExtraRows | 0 | 额外排数，0–10，每排12格 |
| EnableSharing | true | 是否按颜色共享库存 |
| SharedColors | 1–20 | 原版调色板编号，0为未染色 |

联机所有玩家安装同版本，房主管理全局设置；每个玩家独立跟随自己的游戏语言。冰箱、礼物箱和其他特殊箱型不在支持范围内。

1.0.5 颜色设置恢复逐行色块与原版勾选框：勾选表示参与共享。重命名按钮使用游戏原版木框纹理。

1.0.4 使用 SMAPI 滚轮事件并恢复菜单覆盖层之后的库存窗口；删除重复名称，重命名按钮移到名称栏右侧。设置标签明确标注每排12格、最多额外10排。

1.0.3 修正滚轮补丁目标：拦截实际声明在 IClickableMenu 的方法，仅处理支持的箱子菜单。

菜单、提示和日志自动跟随星露谷游戏语言：中文使用中文，英文及其他语言使用英文。没有语言开关，各联机玩家独立跟随各自游戏语言。

适用于本机星露谷 1.6.15 / SMAPI 4.5.2。所有联机玩家须安装同版本。

## 使用

- 通用模组配置菜单 → 彩色共享箱子：房主设置两个独立总开关、增加排数和共享颜色。每排12格，默认增加0排，容量修改默认关闭，共享默认开启。默认未染色箱子不共享，其他20色共享。
- 普通箱、石箱、大箱和大石箱支持。共享组跨地图，容量取组内最大单箱容量，不累加。
- 打开箱子点击右侧“重命名”按钮，留空恢复原名。Ctrl+N 仍保留为备用快捷键。名称归每个箱子，使用 Chests Anywhere 的原生名称字段。
- 鼠标放在箱子物品格上，滚轮上下滚动，每次一排；手中拿着物品时不能滚动。界面不显示库存类别、容量或页数。
- 额外排数最多10排。共享颜色每行显示一个色块，点击右侧勾选框选择是否共享；棕色色块的“未染色”表示默认箱子颜色。
- 箱子菜单关闭后，Ctrl+右键搬起箱子。组内还有箱子时物品留在共享组；最后一个箱子搬起时把库存装入被搬箱子。
- 更改颜色/开关后关闭箱子菜单，等待约1秒处理。联机只由房主迁移库存。
- 改色时旧库存留在旧组。最后一个箱子改色后，旧组暂存；重新染一个同色箱子即可访问。关闭该颜色或共享总开关会导出库存。
- 合并、缩容、关闭共享的溢出先入操作者背包，再掉落处理箱子附近。全局设置按组内最早加入的现存箱子处理。

## 请优先验证（先用备份或测试存档）

1. 两张地图各放同色箱，存取物品，保存重进；不同色与未染色箱应独立。
2. 普通箱和大箱同色，容量取大箱；启用容量、增加1排应增加12格，滚轮滚动后的存取应正常；中英文按钮及配置色块均应可点击。
3. 改色后旧库存不跟随；原组无箱时重新加入原色箱检查恢复。
4. 关闭颜色、缩容、背包装满时检查物品数量和掉落位置。
5. Chests Anywhere 远程存取/名称；Automate 投入取出；联机双方同时存取、改色、搬箱。

已完成针对本机游戏程序集的编译与静态接口检查；尚未完成游戏运行、Automate 实际吞吐、联机并发测试。不能据此保证所有模组无冲突。

## 卸载

不要直接删除带共享库存的模组。房主进入存档，关闭所有箱子菜单，在 SMAPI 控制台输入 `colorchests_export`，等待几秒，确认库存已回到箱子，保存退出后再删除。可用 `colorchests_status` 查看共享组库存。若仍有暂存库存，先放置普通箱再执行导出。

## 从源码构建

安装支持 .NET 6 目标的 .NET SDK，并准备本机游戏及 SMAPI：

```powershell
dotnet build ColorSharedChests.csproj -c Release -p:GamePath="D:/Steam/steamapps/common/Stardew Valley"
```

将输出 DLL、manifest.json、默认 config.json、说明文件及确认后的 LICENSE 放入 `ColorSharedChests` 文件夹发布。不要附带游戏或其他模组 DLL、存档、日志及个人配置。

当前二进制已通过本地 Roslyn 编译；新增 SDK 项目尚未在本环境执行构建，发布时不能标注 CI 已通过。
