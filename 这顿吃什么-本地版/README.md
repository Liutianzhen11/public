# 这顿吃什么 · 本地版

一个完全离线的随机选餐网页。默认菜单、样式和程序都在一个 HTML 文件中，无账号、无后台、无网络请求。

默认菜单：麻辣烫、麻辣香锅、面、饺子、麦当劳、肯得记。支持新增、改名和删除。

[下载完整 ZIP](./这顿吃什么-本地版.zip)

## 下载和打开

下载本目录的「这顿吃什么-本地版.html」（查看文件后选择 Download raw file），或下载整个仓库 ZIP 并解压。请保存实际 HTML 文件，不要把 GitHub 文件展示页面另存为网页。

用电脑端 Chrome 或 Edge 打开下载的 HTML，点击「开始随机」，再点击「暂停」决定这顿吃什么。无需安装、登录或联网。

## 保存到原文件

1. 点击「管理菜单」，新增、编辑或删除菜品。编辑名称后先点「确定」。
2. 点击「保存菜单」。第一次保存时，选择**正在打开的那个本地 HTML 文件**。
3. 浏览器如提示文件修改权限，请允许。
4. 等待页面显示「已写入文件」。同一次使用中再次保存，会直接写回已选文件，通常不必重新选择。

菜单写入 HTML 本身，不依赖浏览器缓存。下次使用任何浏览器打开**保存后的同一个文件**，都会显示修改后的菜单；把这个文件复制到另一台电脑也会携带菜单。

每次重新打开网页后，第一次覆盖保存需要再次选择当前文件并授权。本版不承诺浏览器永久记住权限。仅查看和随机选餐无需授权。

## 浏览器与备用方式

直接覆盖保存支持具有 File System Access API 的电脑端 Chrome／Edge，仍受版本、企业策略和文件权限影响。Safari、Firefox、手机浏览器不保证支持原文件覆盖。

不支持写入或不希望授权时，可点击「下载更新后的 HTML（备用）」。此操作生成新文件，**不会覆盖原文件，也不会把当前草稿标成已写入**。请检查下载完成，以后打开新文件；若需替换旧文件，由你自行移动替换。

## 注意事项

- 文件必须可写，建议存放在普通个人文件夹，不要直接从 ZIP 或只读介质打开。
- 取消文件选择、拒绝权限或写入失败时，修改仍是未保存草稿；请保留网页并重试或备用下载。
- 保存期间不要关闭网页。关闭有未保存修改的页面可能出现浏览器提醒。
- 请勿同时在多个窗口编辑同一文件。程序会在保存前检测外部文件变化并拒绝覆盖，但不能保证消除极短时间内的并发写入。
- 菜品名称最多 20 个字符，最多 100 个菜品，名称不能重复，至少保留一个。
- 选择错文件或文件菜单已变化时，不会直接覆盖；请重新选择当前文件，或备份草稿后打开最新文件。
- 不会上传菜单，也不与在线版同步。公开仓库提供的是六个默认菜品；保存自己的文件不会修改 GitHub。
- 升级时不要用新下载的默认 HTML 直接覆盖自定义版本；先备份自己的 HTML。
- 建议定期复制一份 HTML 作为备份。它包含你保存的菜单，分享文件也会分享这些菜品。
